# تنفيذ تكامل الرصد — تطوير فقط

1. إضافة ترحيل مستقل للجهة والأدلة والطلبات، مع اختبار نشر الفرصة المعتمدة وحفظ هويتها.
2. ربط الحالة المشتركة بالفرص الديناميكية، وإضافة شاشة متابعة مرتبطة بالمشاريع والمهام.
3. تشغيل فحص دوري محدود مستقل عن جلسة المستخدم، مع قفل ومنع التكرار وفحص السياسات عند كل طلب.
4. مراجعة مصادر رسمية وضبط قائمة السماح؛ لا يُعتمد تاريخ أو تمويل آليًا.
5. اختبار الصلاحيات والتزامن والنسخ والاستعادة ودورة العمل كاملة محليًا، ثم نسخة احتياطية وترحيل ونشر التطوير فقط وإعادة اختبارات القبول.

الاعتماد المالي والمراجعة البشرية محفوظان. الإنتاج والنطاق الرئيسي خارج هذا التنفيذ.

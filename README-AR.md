# رادار المانحين — نسخة الفريق 10

نسخة عربية للعمل المشترك داخل جمعية التنمية الأهلية بالمعذر. تستخدم الواجهة
والمشاريع والمرفقات المعتمدة من النسخة التاسعة، مع خدمة مركزية للحسابات والبيانات.

## التشغيل

هذه الحزمة تطبيق خادم Node.js. يستخدم cPanel مدخل `passenger.cjs`، ويظل
`npm start` متاحًا للتشغيل المباشر. اتبع
`DEPLOY-CPANEL-AR.md` للتركيب على cPanel، و`STAFF-GUIDE-AR.md` لتفعيل الفريق.

تتطلب Node.js 22.13 أو أحدث يدعم `node:sqlite`، وقرصًا محليًا دائمًا يمكن لحساب
الاستضافة الكتابة فيه. يوصى بإصدار مصحح وحديث من سلسلة Node.js 22 أو 24.
قاعدة SQLite موجودة على الخادم؛ يتعامل الموظفون معها من خلال التطبيق فقط.

## المحتويات

| المسار | الغرض |
| --- | --- |
| `passenger.cjs` و`app.js` و`server/` | مدخل الاستضافة، والخدمة، والحسابات، والصلاحيات، والتحقق من البيانات |
| `public/` | مجلد الويب العام الذي يربطه cPanel بالتطبيق |
| `private/app/` | الواجهة والأغلفة والمرفقات المحمية بالمصادقة |
| `private/catalog.json` | سجل المشروع الأصلي للتحقق من البيانات والمسارات |
| `views/` | شاشة الدخول |
| `client/` و`source/` | مصدر الواجهة وطبقة عمل الفريق |
| `scripts/` | إنشاء المدير، والتحقق من التركيب، والنسخ الاحتياطي والاستعادة |
| `config.example.json` | نموذج إعدادات التشغيل، يُنسخ إلى `config.json` |
| `QA-REPORT-AR.md` | نتائج التحقق المحلي وما يلزم فحصه على الاستضافة |

ملفات قاعدة البيانات والحسابات والجلسات لا تأتي داخل الحزمة. ينشئ المسؤول حساب
المدير عند التركيب، ثم ينشئ حسابات الموظفين من داخل التطبيق.

للاستضافات التي توفر Run JS Script دون طرفية تفاعلية، يدعم الدليل
`setup:cpanel` لتسليم كلمة مؤقتة للمالك من ملف خاص، مع فرض تغييرها عند الدخول.

ملف الواجهة ودليل التشغيل للنسخة التاسعة محفوظان في `source/` للرجوع إلى
المصدر. اتبع دليل نسخة الفريق الموجود في جذر الحزمة عند تشغيل هذا الإصدار.

## بيانات المشروع

- 30 سجل مشروع أصلي؛ منها 22 مشروعًا بعروض مانحين. يعرض الرادار افتراضيًا 29 فرصة قبل تعديلات الإخفاء والأرشفة، مع ربط التنفيذ السابق لمهارات المستقبل بفرصته الموحّدة.
- «مهارات المستقبل» مشروع واحد للعرضين الأول والثاني، بطلب 265,200 ريال،
  و300 مستفيد، و9 أشهر. سجل التنفيذ السابق محفوظ مستقلًا ومتاح في تفاصيل الفرصة دون احتساب طلب إضافي.
- 45 مرفقًا أصليًا: 23 PDF و22 PowerPoint، و29 صورة غلاف.
- بقيت المراجع والملفات السابقة ضمن المصادر، وبيانات الرصد الأساسية بتاريخ
  22 أكتوبر 2026. لا يمثل تحديث التطبيق رصدًا جديدًا لفرص التمويل.

## حدود الاستخدام

إخفاء المشروع أو أرشفته يغيّر عرضه وحالته المشتركة. الموظفون المصادق عليهم
يمكنهم الوصول إلى الملفات الأصلية للمشاريع؛ لا توجد صلاحيات منفصلة لكل مشروع.
الأدوار تضبط التعديل والإدارة على مستوى التطبيق.

تعديلات الحقول في الرادار لا تعيد تصميم ملفات PDF وPowerPoint أو النصوص داخل
الغلاف. تبقى هذه الملفات مطابقة للحزمة الأصلية.

تعمل النسخة على خادم واحد بقرص محلي. لا تضع قاعدة البيانات في مجلد OneDrive
أو على مشاركة ملفات شبكية، ولا تستخدم هذه الحزمة كتطبيق موزّع على خوادم متعددة.

## تحديث مصدر الواجهة

بعد تعديل `client/team.js` أو `client/team.css`:

```bash
node build-client.cjs
```

ثم أعد تشغيل التطبيق من cPanel. يُحدّث الأمر طبقة الواجهة، ويحافظ على
المرفقات الأصلية وعلى بيانات التشغيل الموجودة في `RADAR_DATA_DIR`.
